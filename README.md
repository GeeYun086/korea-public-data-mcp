# korea-public-data-mcp

대한민국 공공데이터를 Claude가 **직접 조회해서 답하게** 해주는 MCP 서버입니다.

기업 재무제표, 환율·금리 같은 경제 지표, 정부 지원사업 공고, 공공 입찰공고를 물어보면
기관 API를 실제로 호출해 받아온 값으로 답합니다. 기억이나 추측으로 답하지 않습니다.

**현재 상태** — 도구 14개 / 소스 8곳 / 인증키 8개 확보. 전부 실호출로 동작을 확인했습니다.

## 인증키 현황

발급처는 5곳이고, `data.go.kr` 키 하나가 소스 6곳을 담당합니다.

| 발급처 | 환경변수 | 상태 | 비고 |
| --- | --- | --- | --- |
| 금융감독원 OpenDART | `DART_API_KEY` | ✅ | 가입 즉시 |
| 한국은행 ECOS | `ECOS_API_KEY` | ✅ | 즉시~1일 |
| 통계청 KOSIS | `KOSIS_API_KEY` | ✅ | 활용신청 후 승인 |
| 공공데이터포털 | `DATA_GO_KR_API_KEY` | ✅ | **계정당 1개** — 아래 참고 |
| 한국수출입은행 | `KOREAEXIM_*` 3개 | ✅ | 상품별 별도 발급 |
| 기업마당 | `BIZINFO_API_KEY` | ✅ | 신청서 → 이메일 |
| NTIS | `NTIS_API_KEY` | ⏸ **미발급** | 소속기관 등록 + **호출 서버 공인 IP** 필요, 승인 수일 |
| AI Hub | `AIHUB_API_KEY` | ⏸ 보류 | 데이터셋 다운로드용. 공고 수집과 무관 |

### data.go.kr 인증키는 계정당 1개입니다

서비스마다 키가 발급되지 않습니다. **키 1개에 서비스별 사용 권한이 붙는 구조**입니다.

```
인증키   = 신분증 (1개, 고정)
활용신청 = 그 신분증에 붙는 서비스별 출입 권한
```

신청하지 않은 서비스는 같은 키로도 `SERVICE_ACCESS_DENIED_ERROR` 가 납니다.
24개 서비스를 신청해도 `.env` 항목은 늘어나지 않습니다.

**★ Encoding 키가 아니라 Decoding 키를 넣으세요.** 포털은 같은 키를 두 형태로 보여주는데,
`serviceKey` 를 httpx params 로 넘기면 자동 인코딩돼서 Encoding 키는 이중 인코딩으로 실패합니다.

## 설치와 실행

```bash
python -m venv .venv
.venv/Scripts/pip install -e .
cp .env.example .env      # 발급받은 키 입력
```

### Claude Desktop

`%APPDATA%\Claude\claude_desktop_config.json` 의 `mcpServers` 에 추가:

```json
"korea-public-data": {
  "command": "C:\\경로\\public-data-mcp\\.venv\\Scripts\\python.exe",
  "args": ["-m", "korea_public_data_mcp.server"]
}
```

### Claude Code

프로젝트 루트에 `.mcp.json` 을 만들거나 `claude mcp add` 로 등록합니다.
`.mcp.json` 은 실행 파일 절대경로가 들어가므로 `.gitignore` 처리되어 있습니다.

### Docker

stdio 통신이라 **포트를 열지 않습니다.**

```bash
docker build -t korea-public-data-mcp .
docker run -i --rm --env-file .env korea-public-data-mcp
```

> ⚠️ 이미지에 키를 굽지 마세요. 이미지를 받은 사람 전원이 키를 갖게 되고 회수도 안 됩니다.

## 제공 도구 (14개)

**금융 — 기관마다 데이터 성격이 달라 개별 도구로 노출합니다.**

| 도구 | 용도 |
| --- | --- |
| `dart_search_company` | 회사명 → 기업코드. **다른 DART 도구보다 먼저 호출** |
| `dart_get_financial_statements` | 재무제표 전체 (연결 `CFS` / 별도 `OFS`) |
| `dart_get_company_disclosures` | 기간별 공시 목록 |
| `ecos_get_key_indicator` | 기준금리·환율·GDP·물가 바로 조회 |
| `ecos_search_statistics` | 그 외 통계표 검색 |
| `ecos_get_statistic_data` | 통계표 코드로 실제 수치 |
| `kosis_search_statistics` | 통계표 검색 |
| `kosis_get_statistics_data` | 표 단위 일괄 조회 |
| `koreaexim_get_exchange_rates` | 환율 |
| `koreaexim_get_loan_rates` | 대출금리 |
| `koreaexim_get_international_rates` | 국제금리 |
| `data_go_kr_generic_get` | 포털의 다른 서비스 범용 호출 |

**정부사업·조달 — 여러 기관이 같은 "공고"를 제공하므로 통합 도구로 묶습니다.**

| 도구 | 용도 |
| --- | --- |
| `gov_search` | 8개 소스 통합 검색. 기관 지정·분야·지원대상·마감 여부 필터 |
| `gov_list_sources` | 조회 가능한 소스 목록과 각각의 특성 |

```
gov_search(query="수출", target="중소기업")        # 전체를 훑되 소스별 상한 적용
gov_search(query="AI", sources=["조달청"])         # 기관 지정 시 그쪽만
gov_search(domain="procurement")                  # 조달만
```

소스를 지정하지 않으면 **기관별 상한(기본 10건)** 을 겁니다. 나라장터가 2주에 1.6만 건 규모라
상한이 없으면 다른 기관 공고가 전부 묻힙니다.

## 설계 원칙

**키가 없어도 서버는 뜹니다.** 키 검증은 서버 기동이 아니라 *도구 호출 시점*에 합니다.
기관이 늘면 일부는 항상 발급 대기 상태인데, 키 하나 없다고 서버 전체가 안 뜨면
이미 확보한 기관까지 못 씁니다. 키가 없으면 오류 대신 발급 안내 메시지를 반환합니다.

**캐시 문제로도 서버가 죽지 않습니다.** 캐시 디렉터리를 만들 수 없으면 임시 폴더로 물러납니다.

**호출 횟수를 최소화합니다.** 일일 한도가 있고 초과하면 차단 위험이 있어, 한 번에 많이 받습니다.
재무제표는 전체 계정을 한 번에, 통계는 기간 범위를 한 번에 받습니다.

**부분 실패를 정상 취급합니다.** `gov_search` 는 한 기관이 죽어도 나머지 결과를 반환하고,
어느 기관이 실패했는지 응답에 표시합니다.

**계층을 나눕니다.** `clients`(외부 API를 어떻게 부르는가)와 `tools`(모델에게 어떻게 보이는가)를
분리해서, 기관 API가 바뀌어도 도구 이름과 사용법은 그대로 유지됩니다.

```
src/korea_public_data_mcp/
├── server.py       진입점 — 도구 등록, stdio 통신
├── config.py       인증키 관리 및 발급 안내
├── registry.py     소스 메타데이터 (도메인·인증키·별칭·주의사항)
├── core/           HTTP 재시도 · 캐시 · 호출 속도 제한
├── clients/        기관별 호출 및 응답 정규화
└── tools/          MCP 도구 등록
```

## 확장 가이드

**data.go.kr 신규 서비스** — 포털에서 활용신청만 하면 `data_go_kr_generic_get` 으로
**코드 수정 없이** 호출됩니다.

**정부사업·조달 소스 추가** — 두 곳만 건드립니다.

1. `registry.py` 에 `Source` 항목 추가 (도메인·별칭·주의사항)
2. `clients/gov_sources.py` 에 어댑터 함수 작성 후 `FETCHERS` 에 등록

도구 코드는 손대지 않습니다.

**신규 기관 (별도 인증키)** — 위 두 단계에 `config.py` 의 `API_KEYS` 항목 추가가 더해집니다.

## 실호출로 확인한 기관 API 함정

문서에 없어서 직접 호출해야 알 수 있었던 것들입니다.

| 기관 | 함정 |
| --- | --- |
| **나라장터 전반** | **페이지 1이 가장 오래된 건이다.** 사전규격 30일 조회 시 page 1은 7/20, 마지막 페이지가 8/19였다. 그대로 받으면 이미 마감된 건만 잡힌다 |
| 나라장터 계약정보 | 조회 기간 상한이 **7일**(양끝 포함). 8일치를 요청하면 `resultCode 07` |
| 나라장터 발주계획 | 기간 파라미터가 `inqryBgnDate`(8자리). 입찰공고의 `inqryBgnDt`(12자리)와 이름이 다름 |
| 과기정통부 사업공고 | `numOfRows` 를 무시하고 **페이지당 10건**만 반환. 응답도 XML 뿐 |
| 기업마당 | 인증 파라미터가 `serviceKey` 가 아니라 **`crtfcKey`** |
| 한국은행 ECOS | `StatisticTableList` 의 마지막 인자는 키워드가 아니라 **통계표코드**. 검색어를 넣으면 항상 0건 |
| 통계청 KOSIS | `statisticsList.do` 는 주제별 목록 순회 API라 `searchNm` 이 무시된다. 검색은 `statisticsSearch.do` |
| 공공데이터포털 | 인증키는 계정당 1개. **Decoding 키**를 써야 한다 |

## 알려진 제약

| 제약 | 내용 |
| --- | --- |
| **과거 공고 검색 불가** | 저장하지 않고 매번 조회합니다. API가 주는 최근 구간 안에서만 검색됩니다 |
| **알림 없음** | 물어볼 때만 조회합니다. 새 공고 자동 알림 기능은 없습니다 |
| **낙찰정보 미연결** | 필수 파라미터명을 찾지 못했습니다. 후보 10종 모두 `resultCode 08` — 참고문서 확인 필요 |
| **IITP·한국연구재단 R&D 공고** | 과기정통부 API에 **포함되지 않음**(50건 전수 확인). NTIS가 유일한 경로 |
| **디지털서비스몰** | 전용 API 없음. 종합쇼핑몰 API는 물품 카탈로그라 SW·클라우드 미포함(100건 확인) |
| **수집 불가 확정** | 학교장터(S2B) · e나라도움 · IRIS · 중소기업확인서 검증 — 해당 기관이 미개방 |

**캐시는 프로세스별로 분리됩니다.** 사용자마다 서버 프로세스가 따로 뜨므로 캐시와 호출 속도 제한이
공유되지 않습니다. 팀 단위로 쓰면 일일 한도를 각자 소진합니다. 중앙 서버 방식으로 전환하면
해소되고, NTIS 의 IP 등록 문제도 함께 정리됩니다.
